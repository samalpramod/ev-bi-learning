# EVCharge BI Learning Project

## Purpose

Hands-on learning project for Business Intelligence, Data Analytics and Enterprise BI Architecture.

The project uses a fictional EV charging business to learn BI concepts through practical implementation.

## Learning Goals

* Business Intelligence fundamentals
* SQL for analytics
* Data modeling
* Star schema
* Power Query
* DAX
* Power BI dashboards
* BI architecture
* API-based data integration
* REST vs GraphQL
* Enterprise BI design

## Technology Stack

* Power BI
* MySQL 8.3
* SQL
* Python 3.12
* FastAPI
* GraphQL
* Git
* GitHub
* VS Code

## Project Domain

EV charging business intelligence.

The system will contain:

* Operators
* Locations
* Charge Points
* Customers
* Transactions
* Payments

## Learning Method

The project follows a Scrum-based learning approach.

Each learning day includes:

1. Concept learning
2. Practical implementation
3. Documentation
4. Git commit

## Planned Duration

Approximately 8 weeks.

## Daily Investment

Approximately 2 hours per day.

## Project Architecture

The project will progressively evolve from a simple operational database into an analytical BI architecture and finally an enterprise-oriented BI solution.
